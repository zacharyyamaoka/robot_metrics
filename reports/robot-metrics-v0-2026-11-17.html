API at a glance

Configure a stock metric and name it, take the pendulum arm's metrics from the catalog, score a run live and from the whole recording, judge a pass/fail target kept apart from the math, and group many runs by station and rung. One script on its own; it reads round 8's recordings, which are not public. Each line's output sits right under it, from the run that built this page.

from robot_metrics import DEGREES, Alias, ErrorStat, Objective, catalog, summarize
from robot_metrics.datasets import onedof_round8
